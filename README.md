# تعمیرینو

تعمیرگاهت رو با گوشی مدیریت کن.

اپلیکیشن مدیریت تعمیرگاه برای تعمیرکاران و مراکز خدماتی کوچک ایرانی — مدیریت مشتری، سفارش تعمیر، فاکتور، بدهی و یادآوری، همه از داخل یک اپ ساده اندرویدی.

## امکانات (نسخه فعلی)

- ثبت‌نام و ورود
- مدیریت مشتریان و دستگاه‌ها
- ثبت و پیگیری سفارش تعمیر
- فاکتور فارسی قابل چاپ و اشتراک‌گذاری (PDF)
- ثبت پرداخت و پیگیری بدهی
- یادآوری تحویل، تماس و سرویس بعدی
- انبار ساده قطعات
- گزارش درآمد و سود

## توسعه

این پروژه با Flutter نوشته شده و کاملاً روی Android + Termux قابل توسعه است؛ Build نهایی از طریق GitHub Actions انجام می‌شود.

### پیش‌نیاز محلی (Termux)

نیازی به نصب Flutter روی گوشی نیست. فقط Git لازم است.

### ساخت APK

هر Push به شاخه `main`، به‌صورت خودکار توسط GitHub Actions ساخته می‌شود. فایل APK از تب Actions همان Commit، بخش Artifacts، قابل دانلود است.

## متغیرهای محیطی

فایل `.env.example` را کپی کرده و به `.env` تغییر نام دهید، سپس مقادیر واقعی را وارد کنید. فایل `.env` هرگز نباید Commit شود.

## ساختار پروژه

به فایل `PROJECT_STATUS.md` برای وضعیت فعلی پروژه مراجعه کنید.
